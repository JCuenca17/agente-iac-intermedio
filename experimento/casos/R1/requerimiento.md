Necesito una API de ejemplo basada en contenedores: un clúster de AWS Fargate que aloje dos servicios expuestos a través de una API HTTP de API Gateway. El servicio "Food store" permite registrar (PUT) y consultar (GET) alimentos en /foodstore/foods/{foodId}, y el servicio "Pet store" hace lo mismo con mascotas en /petstore/pets/{petId}. Cada servicio guarda sus datos en su propia tabla de DynamoDB. Los usuarios no autenticados solo pueden consultar; para registrar hay que autenticarse con un grupo de usuarios de Cognito. Los contenedores corren en subredes privadas de una VPC propia, y la API llega a ellos mediante un enlace de VPC y descubrimiento de servicios.
